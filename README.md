# Tails-NIDL
Tails' Nightmare In Dreamland
Use a legally obtained kirby nidl rom
Patch with any rom patcher, I use rompatcher.js online
I was able to beat the game, so it should be decent enough. If you get stuck anywhere, you should be able to find a way to proceed
The only things unaccesible are areas locked behind fire and hammer. I knew that going in, but since the game was beatable as kirby with no copy abilities, I thought i'd leave those areas for kirby only lol. 
Have fun, I only spent a few sessions working on this so I apologize if things arent perfect
